# Chicken's Anglet — Site complet

Tous les fichiers nécessaires au site sont inclus.

## Contenu
- index.html : site complet, styles et panier interactif inclus
- assets/interieur.jpg : photo du restaurant
- vercel.json : configuration Vercel
- README.md : instructions

## Installer sur GitHub
1. Crée un nouveau dépôt GitHub.
2. Décompresse le ZIP.
3. Ajoute les fichiers **index.html**, **vercel.json**, **README.md** et le dossier **assets** à la racine du dépôt.
4. Clique sur « Commit changes ».
5. Sur Vercel, importe ce nouveau dépôt. Framework Preset : Other ; Root Directory : ./ ; Output Directory : laisser vide.

## Avant la mise en service
Le panier prépare un récapitulatif, mais n'envoie pas de commande.
Le téléphone n'est pas configuré, car le numéro officiel n'a pas été fourni.
Les prix et horaires sont ceux des captures Instagram transmises : les confirmer avec le restaurant.
